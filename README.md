# 🧠 Spine Condition Classification using Machine Learning

This project aims to classify whether a person's spine is **Normal** or **Abnormal** based on medical attributes like pelvic tilt, lumbar lordosis angle, and more. The classification models were built using various supervised ML algorithms.

## 📌 Problem Statement
Predict spinal health condition (Normal vs Abnormal) using biomechanical features.

## 🛠️ Techniques Used
- Exploratory Data Analysis (EDA)
- Outlier Removal (IQR-based, Skewed-tail methods)
- Feature Scaling (MinMaxScaler)
- ML Models: Logistic Regression, Random Forest, SVM, Decision Tree, KNN
- Model Evaluation: Accuracy, Confusion Matrix, F1-Score

## 📊 Results
Achieved high accuracy with ensemble models and validated using cross-validation.

## 🧪 Sample Prediction
Given a test input, the model can predict the class (0: Normal / 1: Abnormal).

## 🔗 Run the notebook
All code is in `Spine Condition Prediction.ipynb`. You can clone and run it using Jupyter Notebook.
